# customer-churn-prediction
An end-to-end machine learning project for predicting telecom customer churn using Logistic Regression, Decision Tree, and Random Forest. Includes data preprocessing, EDA, feature engineering, hyperparameter tuning, and model evaluation to identify customers at risk of leaving.

Project Overview:
Predict customer churn using machine learning techniques and identify customers at risk of leaving telecom services.
|| Features:
1)Data preprocessing and cleaning
2)Exploratory Data Analysis (EDA)
3)Feature engineering
4)Logistic Regression, Decision Tree, and Random Forest models
5)Hyperparameter tuning using GridSearchCV
6)Model evaluation using Accuracy, Precision, Recall and F1-score
7)Feature importance analysis
|| Tech Stack:
1)Python
2)Pandas
3)NumPy
4)Matplotlib
5)Seaborn
6)Scikit-learn
|| Results
Best model: Random Forest
Accuracy: 82%
Recall: 55%
